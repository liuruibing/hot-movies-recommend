# 🎬 热播影视推荐 (Hot Movies & TV Shows Recommendation)

2026 年精选影视推荐页面 - 紧跟潮流 · 品质推荐

## 📖 项目简介

这是一个精美的影视推荐静态页面，展示当下热播的：
- 🔥 热门短剧
- 📺 精品电视剧
- 🎌 精选动漫

页面采用现代化设计，包含响应式布局、渐变色彩、卡片式展示和流畅的动画效果。

## ✨ 特性

- 🎨 现代化 UI 设计，渐变背景色彩
- 📱 响应式布局，适配移动端和桌面端
- 🎭 三大板块：短剧、电视剧、动漫
- ⭐ 评分、集数、类型等信息展示
- 🔗 直达观看链接（抖音、快手、腾讯、爱奇艺、B 站等）
- ✨ 滚动动画效果

## 🚀 使用方式

直接在浏览器中打开 `index.html` 即可预览页面。

```bash
# 本地预览（需要 Python）
python3 -m http.server 8080

# 然后访问 http://localhost:8080
```
